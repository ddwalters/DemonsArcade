# HUD presentation

## Current

- Party HUD is an authored GameUI/HUDCanvas child. Variable rows show default portrait, name, level, health, and mana; only the player shows stamina. Resource labels are omitted and colors distinguish them.

## Agreed

- The roster determines which rows appear. UI reads current character records. Portraits come from linked Node Tree characters.
